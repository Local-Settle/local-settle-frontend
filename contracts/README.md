# Backend API contract

`backend-openapi.json` is the versioned OpenAPI snapshot generated by the backend CI workflow. When backend API request or response schemas change, regenerate the backend contract and update this snapshot in the same change.

The frontend CI `contract:check` step compares the required fields in the Offer, Order, and PaymentMethod request/response schemas with the corresponding TypeScript models. This catches backend contract changes that would leave the frontend models unable to represent required API data.
